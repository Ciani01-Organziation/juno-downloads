# Juno downloads

Official device releases for Juno. Application source is maintained privately.

Early Android test builds are available on the [Releases page](https://github.com/Ciani01-Organziation/juno-downloads/releases). Read the tested features and limitations before installing. There is no production Android release yet.

## Android

Juno requires Android 8.0 or later. Download an APK only from a published release here. Release notes identify tested features, known limitations, and the file checksum.

## iPhone

An APK cannot be installed on iPhone. iOS distribution requires an Apple-supported installation method; a personal-team Xcode build is not a general download for members.
